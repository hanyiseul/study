Spring Boot + MariaDB

회원 관리 API 실습

이 화면은 정적 HTML에서 fetch()로 Spring Boot REST API를 호출하고, MariaDB에 저장된 회원 데이터를 조회·등록·수정·삭제하는 흐름을 확인한다.

전체 회원 0
활성 회원 0
비활성 회원 0
삭제 상태 0

회원 등록

POST /api/members 요청을 전송한다.

회원 수정

PUT /api/members/{id} 요청을 전송한다.

회원 목록

GET /api/members 응답 결과를 테이블로 출력한다.

대기 중
ID 이메일 이름 역할 상태 로그인 수 최근 로그인 생성일 기능
회원 목록을 불러오는 중입니다.
